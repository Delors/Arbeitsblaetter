# Wortschlangen – Lösungsvorschläge

Diese Datei enthält die Musterlösungen zum Arbeitsblatt. Bei der offenen Aufgabe 4 sind die Antworten Beispiele – jede eigene, regelkonforme Wortschlange ist möglich.

## Aufgabe 1

1. `amsamstaggehenwirinskino.` → **Am Samstag gehen wir ins Kino.** *(Samstag und Kino = Nomen, groß)*
2. `ichhoffe,dassduheutekommst.` → **Ich hoffe, dass du heute kommst.** *(dass: Ersatzprobe geht nicht; heute = Adverb, klein)*
3. `wirtreffenunsammontagmorgen.` → **Wir treffen uns am Montagmorgen.** *(Montagmorgen = Nomen, zusammen, groß)*
4. `wirsehenheuteabendfern.` → **Wir sehen heute Abend fern.** *(heute klein, Abend = Nomen, groß)*
5. `dieschuleistmontagsbesonderslang.` → **Die Schule ist montags besonders lang.** *(montags = Adverb, klein)*
6. `daslesenmachtmirspaß.` → **Das Lesen macht mir Spaß.** *(nominalisiertes Verb, groß)*
7. `allesgutezumgeburtstag!` → **Alles Gute zum Geburtstag!** *(nach „alles" wird das Adjektiv zum Nomen → Gute groß)*
8. `siekannschnellrechnen.` → **Sie kann schnell rechnen.** *(rechnen = Verb, klein)*

## Aufgabe 2

1. `kennstdudasmädchen,dasdortdrübensteht?` → **Kennst du das Mädchen, das dort drüben steht?** *(erstes das = Artikel, zweites das = Relativpronomen, Ersatzprobe „welches")*
2. `einestagesfandicheinenschatz.` → **Eines Tages fand ich einen Schatz.** *(Genitiv des Nomens → Tages groß)*
3. `wirfahrendasgleicheautowieihr.` → **Wir fahren das gleiche Auto wie ihr.** *(Adjektiv vor Nomen → gleiche klein!)*
4. `dasschnellelaufenistgesund.` → **Das schnelle Laufen ist gesund.** *(schnelle klein, Laufen groß)*
5. `anweihnachtenbekommenwirgeschenke.` → **An Weihnachten bekommen wir Geschenke.** *(Feiertag → groß)*
6. `ichhabeetwasanderesvor.` → **Ich habe etwas anderes vor.** *(„anderes" nach „etwas" → in der Regel klein!)*
7. `esgibtnichtsunmögliches.` → **Es gibt nichts Unmögliches.** *(nach „nichts" → Unmögliches groß)*
8. `indernachtwarallesruhig.` → **In der Nacht war alles ruhig.** *(Nacht = Nomen → groß; alles = Pronomen → klein)*

## Aufgabe 3

1. `gesternabendhabenwirsolangegefeiert,dassichnachtskaumgeschlafenhabe.` → **Gestern Abend haben wir so lange gefeiert, dass ich nachts kaum geschlafen habe.** *(Abend groß, nachts klein; so …, dass)*
2. `deraltemannsagte,dassdaswetterbaldschlechterwird,undgingnachhause.` → **Der alte Mann sagte, dass das Wetter bald schlechter wird, und ging nach Hause.** *(alte = Adjektiv vor Nomen → klein; dass = Konjunktion; das Wetter = Artikel)*
3. `beimlautensingenhabeichmicherkältet,deshalbsingeichjetztleise.` → **Beim lauten Singen habe ich mich erkältet, deshalb singe ich jetzt leise.** *(Adjektiv „lauten" klein, Singen groß; singe = Verb, klein)*
4. `amwochenendefahrenwiransmeer,weilderstranddortsoschönist.` → **Am Wochenende fahren wir ans Meer, weil der Strand dort so schön ist.** *(Wochenende groß; ans = an das; schön = Adjektiv, klein)*

## Aufgabe 4 (Beispiele)

`daslesenmachtmiramwochenendebesondersvielspaß.`

→ **Das Lesen macht mir am Wochenende besonders viel Spaß.**

*(enthält: das, Nominalisierung „Das Lesen", Zeitangabe „am Wochenende")*

`ichhoffe,dasswiramdienstagabendetwasschönesunternehmen.`

→ **Ich hoffe, dass wir am Dienstagabend etwas Schönes unternehmen.**

*(enthält: dass, Zeitangabe „am Dienstagabend", Nominalisierung „etwas Schönes")*
