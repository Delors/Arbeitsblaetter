# Mathematische Fachbegriffe – Übungsblatt

## Das merkst du dir!

| Rechenart | Beispiel | Fachbegriffe |
| --- | --- | --- |
| Addition (Plus-Rechnen) | 8 + 5 = 13 | Summand + Summand = Summe |
| Subtraktion (Minus-Rechnen) | 20 − 13 = 7 | Minuend − Subtrahend = Differenz |
| Multiplikation (Mal-Rechnen) | 6 · 7 = 42 | Faktor · Faktor = Produkt |
| Division (Geteilt-Rechnen) | 45 : 7 = 6 R 3 | Dividend : Divisor = Quotient und Rest |

## Aufgabe 1: Verbinde!

Welcher Begriff passt zu welcher Erklärung? Verbinde mit einem Strich.
Beispiel: Die Differenz ist das Ergebnis einer Subtraktion.

|     |     |
| --- | --- |
| 1) Dividend | a) das Ergebnis einer Multiplikation |
| 2) Divisor | b) die Zahl, die geteilt wird |
| 3) Produkt | c) das Ergebnis einer Division |
| 4) Quotient | d) die Zahl, durch die geteilt wird |
| 5) Faktor | e) eine Zahl in einer Malaufgabe |
| 6) Summe | f) das Ergebnis einer Addition |

## Aufgabe 4: Richtig oder falsch?

Kreuze an: Ist die Aussage richtig oder falsch?
Beispiel: „Das Ergebnis einer Addition heißt Differenz." – falsch, es heißt Summe.

| Nr. | Aussage | richtig | falsch |
| --- | --- | --- | --- |
| 1) | In der Aufgabe 82 : 9 ist 82 der Divisor. |     |     |
| 2) | Das Ergebnis einer Multiplikation heißt Produkt. |     |     |
| 3) | In der Aufgabe 15 − 7 = 8 ist 15 der Minuend. |     |     |
| 4) | Das Ergebnis einer Division heißt Summe. |     |     |
| 5) | In der Aufgabe 4 · 8 = 32 sind 4 und 8 Faktoren. |     |     |
| 6) | In der Aufgabe 63 : 9 = 7 ist 9 der Dividend. |     |     |
| 7) | Der Rest ist immer kleiner als der Divisor. |     |     |
| 8) | In der Aufgabe 12 + 9 = 21 ist 21 ein Summand. |     |     |
