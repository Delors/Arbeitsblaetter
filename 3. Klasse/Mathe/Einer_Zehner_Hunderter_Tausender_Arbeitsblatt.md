# Einer, Zehner, Hunderter und Tausender

## Das musst du wissen

| Stellenwert | Abkürzung | Wert |
| --- | --- | --- |
| Einer | E | $1$ |
| Zehner | Z | $10$ |
| Hunderter | H | $100$ |
| Tausender | T | $1000$ |

Jede Stelle links ist zehnmal so viel wert wie die Stelle rechts daneben:

$$10\text{ E} = 1\text{ Z}$$
$$10\text{ Z} = 1\text{ H}$$
$$10\text{ H} = 1\text{ T}$$

Beispiele:

$$10\text{ Z} + 1\text{ E} = 100 + 1 = 101$$

$$12\text{ Z} + 12\text{ E} = 120 + 12 = 132$$

$$23\text{ T} = 23\,000$$

**Achtung:** $13\text{ T} = 13\,000$, aber $23\text{ T} = 23\,000$.
